# JustCropIt ✂️

A modern, client-side photo editor built with Vue 3 and TypeScript. Edit, crop, flip, and batch process images entirely in your browser - no server required!

## ✨ Features

- 🖼️ **Multi-image upload** - Upload and manage multiple photos
- ✂️ **Advanced cropping** - Precise crop with visual feedback
- 🔄 **Flip operations** - Horizontal and vertical flipping
- 📦 **Batch operations** - Apply edits to multiple images at once
- 💾 **Client-side storage** - Uses IndexedDB for persistent storage
- 📥 **Batch download** - Download selected images as ZIP
- 🎨 **Copy/Paste settings** - Copy edit settings between images
- 📱 **Responsive design** - Works on desktop and mobile
- ⚡ **Zero backend** - All processing happens in the browser
- 🎯 **Drag-to-select** - Intuitive multi-selection interface
